# 구현 로드맵

현재 제품 우선순위의 기준은 [제품 로드맵](product/roadmap.md)과 [개선·추가 작업 목록](product/backlog.md)입니다. React/Tauri 데스크톱과 Node/Fastify API 전환은 코드 기준 완료됐습니다. 이어서 테스트 조직의 업무 인수와 배포를 확인합니다.

## 현재 단계

### 1. 핵심 업무 흐름 인수

예약 생성·충돌·수정·노쇼, 상담·동의·시술, 복합 수납, 회원권/재고 반영, 환불, 일·월 마감을 테스트 조직에서 연결해 확인합니다. 병합·환불·서명처럼 되돌리기 어려운 업무는 격리된 테스트 고객으로 검증합니다.

### 2. 운영 배포·복구

HTTPS API와 관리자 API를 분리 배포하고, Windows Native 설치본·서명·업데이트·복구를 새 PC에서 확인합니다. 장애 로그와 DB/Storage 백업 복구 절차도 인수 조건에 포함합니다.

### 3. 남은 P2 운영 통제

- TRT-11: 시술 소모품 재고와 회원권 횟수 차감 연결
- SEC-10: 감사 이벤트 조회 화면과 보관·파기 정책
- SEC-09: 다중 API 인스턴스 운영 전 로그인 제한 외부 저장소 적용

### 4. 제품 확장

CARE/MKT 사후관리와 동의 기반 재방문 안내를 담당자·기한·예약·매출 근거에 묶어 검토합니다. 문자/알림톡 공급자 계약, 동의 범위, 실패·철회 이력을 확정한 뒤 구현합니다. 자동화·AI·다지점·확정 손익은 핵심 원장 인수 이후 확장합니다.

## 전환 이력

Python FastAPI/PySide6에서 Node/Fastify + React/Tauri로의 코드 전환은 완료됐습니다. 과거 구현 계획과 검증 결과는 [변경 이력](product/changelog.md), [기능 대응표](product/react-tauri-parity.md), `docs/superpowers`의 원본 설계·계획에 보존합니다. 과거 날짜별 “다음 작업” 문구는 현재 우선순위가 아닙니다.

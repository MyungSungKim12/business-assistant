# 환불·취소 반대 원장 계획 — 2026-10-07

기능: SALE-003, WAL-003, INV-002 · 선행: 025~028 · 상태: `in-progress`

## 1차 범위

- 현금·카드·이체 원영수증별 부분/전체 환불 기록과 재무 지출 반대 거래.
- 회원권 사용 건 전체 취소와 금액/횟수 복원. 부분 횟수·부분 사용 취소는 허용하지 않는다.
- 누적 순수납이 0원이 되는 전체 취소에서 판매 상품 재고를 복원하고, 해당 판매로 발급된 회원권을 회수한다.
- 발급 회원권의 혜택이 이미 사용되었거나 잔액이 변경되었다면 전체 취소를 원자적으로 거부한다.
- 부분 환불은 판매 이행을 유지하고 방문을 미수 상태로 되돌린다. 전체 취소는 장바구니/방문을 취소 상태로 고정해 재수납하지 않는다.
- 카드사·은행 취소 요청은 실행하지 않는다. 사용자가 외부 취소를 확인한 뒤 이 시스템에 기록한다.

## 원장·재시도 계약

- 환불은 원영수증 또는 회원권 사용 원장 하나를 반드시 참조한다.
- 원영수증 누적 환불은 원수납액을 초과할 수 없다. 회원권 사용 취소는 한 번만 가능하다.
- 환불, 재무 지출, 지갑 복원, 방문/장바구니 상태, 전체 취소의 재고/발급 반대 원장을 한 트랜잭션에 기록한다.
- 원거래와 반대 거래는 수정·삭제하지 않는다. 작업 ID 재전송은 같은 결과만 반환한다.
- owner/admin만 환불 기록을 만들며 member는 원거래·환불 내역을 조회한다.

## 인터페이스

- RPC `refund_visit_payment(... p_source_id,p_amount,p_reason,p_expected_cart_version,p_operation_id,p_confirmed)` → 환불 포함 수납 스냅샷.
- API `POST /organizations/{organization_id}/visits/{visit_id}/payment-refunds`.
- 요청: `source_id`, `amount`, `reason`, `expected_cart_version`, `operation_id`, `confirmed=true`.
- 회원권 사용 출처는 정확한 적용 금액 전체만 허용하며 원래 금액/횟수를 복원한다.

## 남은 범위

- 외부 카드/PG 취소 실행·결과 조회·입금 대사, 승인자 2인 결재, 일 마감 이후 별도 승인.
- 발급 회원권 부분 환불 가치 계산, 사용 후 위약금/공제, 기간 연장·정지.
- 수당·세금·할인·원가의 반대 원장과 실제 회계 정책.

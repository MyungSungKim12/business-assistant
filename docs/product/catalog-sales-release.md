# 상품·회원권 판매 연결 적용 안내

작성일: 2026-10-07 · 기능: INV-001/002, WAL-001/004, SALE-001 · 담당: Codex  
상태: 1차 판매 흐름 로컬 구현·검증 완료, 실환경 인수 전 `in-progress`

## 사용할 수 있는 흐름

매출·지출 → 결제 장바구니 → **상품 · 회원권 관리**에서 판매 항목을 등록한다. 실물 상품은 입고 수량과 사유를 기록하고, 회원권은 판매가와 제공 금액·횟수·유효기간을 각각 입력한다. 방문을 선택한 뒤 상품 또는 회원권을 장바구니에 담고 기존 수납 화면에서 결제를 기록한다.

판매 조건은 장바구니에 담는 시점의 스냅샷으로 고정된다. 이후 상품 가격이나 회원권 혜택을 바꾸어도 이미 담은 항목과 결제 완료 후 발급되는 혜택은 바뀌지 않는다. 회원권은 완납 시 고객 잔여 혜택에 표시된다. 실물 상품은 완납과 동시에 재고가 차감되며 재고가 부족하면 영수·재무 기록을 포함한 전체 수납 요청이 취소된다.

실물 상품이 든 장바구니는 재고 예약 없이 부분 수금 상태가 생기지 않도록 한 번에 완납해야 한다. 시술·회원권만 있는 방문은 기존 부분 수금을 유지한다.

## SQL 적용 순서

사용자는 2026-10-06에 024, 025, 026 적용을 완료했다고 보고했다. 이 보고를 운영 DB에서 직접 확인하지는 않았다. 027은 이번 작업에서 운영 DB에 실행하지 않았다.

1. Supabase SQL Editor에서 현재 적용 기록과 대상 프로젝트를 확인한다.
2. 024 → 025 → 026이 적용된 DB에 [027_catalog_sales.sql](https://github.com/MyungSungKim12/business-assistant/blob/main/migrations/027_catalog_sales.sql)을 한 번 실행한다.
3. 같은 소스 버전의 서버와 데스크톱을 재시작한다.
4. 별도 테스트 조직에서 상품 등록 → 입고 → 방문 완납 → 재고 감소, 회원권 판매 → 완납 → 고객 잔여 혜택 표시를 확인한다.

024~026을 다시 실행할 필요는 없다. 027은 기존 완납 방문에 재고 출고나 회원권을 소급 생성하지 않는다.

## 권한과 데이터 보호

- owner/admin: 상품·회원권 등록/수정, 입고, 장바구니 추가.
- member: 카탈로그와 고객 보유 회원권 조회만 가능.
- 테이블 직접 쓰기는 차단하고 조직·역할을 검사하는 RPC로만 변경한다.
- 입고·판매 출고·회원권 발급 원장은 삭제/수정할 수 없다.
- 작업 ID, 예상 버전, 판매 행 고유 연결로 통신 재시도 시 중복 입고·출고·발급을 막는다.
- 다른 조직의 카탈로그·재고·회원권은 RLS와 RPC에서 모두 거부한다.

## 검증 기록

- 격리 DB 전체 **98개 시나리오 묶음 통과**. 신규 카탈로그 판매 7개는 입력 경계, 역할/조직 격리, 직접 쓰기 차단, 입고 재시도, 동일 상품의 여러 방문 판매, 부분 수금 거부, 재고 부족 전체 롤백, 판매 조건 스냅샷, 회원권 1회 발급, SQL 반복 실행, 여러 상품의 원자 출고를 포함한다.
- 서버/common **428 passed**. API 요청·권한·오류 변환과 사용자 토큰 RPC, 조직/ID/합계가 잘못된 성공 응답 차단을 확인했다.
- Qt 데스크톱 **225 passed**. 카탈로그 등록/수정/입고, 장바구니 추가, 읽기 전용, 회원권 잔액, 작성 중 판매 조건·입고 입력 보호와 재시작 후 동일 요청 재시도 동선을 확인했다. 복구 정보는 서버 주소+사용자+조직별로 분리하고 디스크 저장 실패 시 요청을 보내지 않는다. 통신 결과가 불명확한 뒤 로그인·권한 오류가 발생해도 기존 요청 ID를 유지하며, 손상된 복구 정보가 있으면 새 저장·입고를 잠근다.
- Ruff 전체와 `git diff --check` 통과.

검증에는 앱에 포함된 Python 3.12.14 보조 환경과 PGlite를 사용했다. 기본 Python 3.13 차단 문제는 이번 범위에서 변경하지 않았다. PGlite 직렬 실행은 실제 PostgreSQL의 다중 연결 잠금 경합을 대신하지 않는다. 실제 Supabase 왕복, Windows 화면 육안 검수, 혼합 DPI, 운영 재고 대사는 미검증이다.

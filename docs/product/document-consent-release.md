# 발행본 손서명·교부·철회 이력

2026-09-28 · DOC-004 · 코드 구현 완료 / Python·Qt·실환경 검증 대기.
9월23일 시작한 작업을 이어서 마무리했다. 운영 DB 적용·배포·커밋은 하지 않았다.

## 사용 흐름

시술관리 → 문서 발행·이력 → 발행 이력에서 문서 선택 → **선택한 발행본 · 서명·교부·철회**.

1. 보존된 원문과 서식 버전을 확인한다. 손서명 탭에서 서명자 이름을 입력하고 고객이 직접 서명한다. 직원이 원문 확인과 직접 서명 사실을 확인 체크한 뒤 저장한다.
2. 교부 확인 탭에서 실제 외부 교부 방법(종이/이메일/문자/기타), 수령인, 참조 자료와 메모를 기록한다. 실제 전달을 확인한 경우에만 체크하고 저장한다. 이 기능은 메시지를 발송하거나 파일을 출력하지 않는다.
3. 철회 요청이 있으면 사유와 확인 체크를 남긴다. 철회 후 새 서명·교부·철회 추가는 차단하며 원문·서명·과거 교부 기록은 보존한다.
4. 전체 이력에서 각 행위의 기록자와 서버 기록 시각, 당시 입력을 조회한다. 교부는 여러 번 기록할 수 있고, 서명은 해당 발행본에 한 번만 저장한다.

이 기능은 직원 로그인하에 **현장 손서명을 보관**한다. 고객 본인인증, 인증서/외부 전자서명 검증, 대리인 자격 확인은 구현하지 않았다. 실제 교부 시각을 소급 입력하지 않으며 표시 시각은 시스템 기록 시각이다. 잘못된 서명/교부의 별도 정정 이벤트, 발행본 PDF 출력, 자동 전송·수신 증명은 후속 범위다. 오류를 고치기 위해 저장된 서명을 덮어쓰지는 않는다.

## 보존·복구 규칙

- 서명은 정규화 좌표로 저장되어 화면 크기를 바꿔도 원본 좌표를 유지한다. 최대 50획, 획당 500점, 합계 5,000점이며 서로 다른 좌표가 두 개 이상 필요하다. 범위 밖 좌표/불리언/빈 서명은 API·DB에서 거절한다.
- DB는 변경 불가능한 발행본의 제목·본문·서식 버전으로 SHA256 확인값을 계산해 각 이벤트에 묶는다. 사용자에게 이를 본인인증 완료로 표시하지 않는다.
- 모든 이벤트는 추가만 가능하며 수정/삭제/잘라내기를 차단한다. 기록자·시각·순번은 DB가 결정한다. 회원은 조회만, owner/admin만 기록한다. API는 고객·시술 및 문서 기능 권한을 모두 검사하고 DB도 조직과 역할을 검사한다.
- 같은 요청 재시도는 기존 이벤트를 반환한다. 다른 내용/기록자에 동일 요청 ID를 재사용하거나 오래된 순번으로 변경하면 충돌한다. 철회 이후에도 이미 성공한 동일 요청의 재확인은 가능하다.
- 저장 실패 시 이름·손서명·사유·메모를 보존한다. 결과가 불명확하면 다른 변경을 잠그고 같은 요청 재시도를 제공한다. 충돌 시 입력을 보존하고, 새로고침 전에 버리기 여부를 묻는다.
- 한 탭을 저장해도 다른 탭의 미저장 입력은 유지한다. 처리 중 닫기/이동/앱 종료는 막고, 미저장 입력을 버리려면 확인을 받는다. 읽기 사용자는 입력할 수 없다.
- 이력을 250개 단위로 조회하고 순번의 연속성을 검사한다. 누락된 페이지를 정상 상태로 취급하지 않는다. 실제 PostgREST 행 제한 설정과 다중 클라이언트 동시성은 실환경 검증이 필요하다.

## 다른 PC 적용·검증

기존 문서 발행 기능과 migration019까지 적용한 대상 환경을 확인하고 백업 후 `020_document_consent.sql`을 적용한다. 새 서버와 데스크톱을 함께 재시작한다. 실제 고객 데이터를 사용한 시범 기록을 만들지 말고 별도 검증 조직/고객으로 확인한다.

```powershell
uv run --package business-assistant-server pytest apps/server/tests packages/common/tests -q --tb=short
uv run --package business-assistant-desktop pytest apps/desktop/tests -q --tb=short
uv run --package business-assistant-desktop mypy apps/desktop/src apps/server/src packages/common/src
npm test --prefix scripts/db-tests
uv run ruff check .
uv run ruff format --check .
```

실제 화면: 마우스 손서명·지우기·리사이즈·재조회, 확인 체크 누락, 저장 응답 유실 재시도, 중복 서명 거절, 교부 반복, 철회 후 비활성화, 별도 탭 작성 중 다른 탭 저장, 창 X/부모 창/앱 종료 취소, 회원 읽기 전용, 다른 조직 미노출을 확인한다. 두 클라이언트의 같은 순번 변경과 실제 PostgREST 응답·페이지 제한도 검증한다.

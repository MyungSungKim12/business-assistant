# AI 업무 보조

갱신일: 2026-09-18 · 상태: planned

## 목적·진입점

현재 고객·기록·지표를 근거로 요약과 초안을 만들고 사람이 확인하도록 돕는다. 업무 화면에서 진입하고 관리자용 설정은 공통 설정에 둔다.

## 기능 추적

| ID | 우선 | 상태 | 범위 |
| --- | --- | --- | --- |
| AI-001 | P0 | planned | 방문 전 요약·상담 기록 초안·지표 설명 |
| AI-002 | P0 | planned | 근거 기록 링크와 데이터 기준 시점 |
| AI-003 | P1 | planned | 생성 초안과 확정 기록 분리 |
| AI-004 | P1 | planned | 데이터 부족/오류 시 명확한 실패 및 사용량 관리 |

## 데이터 계약

generation_id, source_record_ids, source_versions, model_version, prompt_version, created_at, approval_status. 식별자에는 조직 경계를 적용한다. 기존 API에 없는 필드는 구현 전에 계약과 마이그레이션을 검토한다.

## 업무·복구 흐름

허용된 자료 선택 → 생성 → 근거와 누락 확인 → 직원 수정 → 저장. 생성 실패 시 원본 입력을 유지하며 외부 발송/결제/보관은 자동 확정하지 않는다.

## 인수 조건

- [ ] 근거 없는 방문·시술 기록을 사실로 채우지 않는다. 다른 조직이나 권한 없는 필드를 검색/요약하지 않는다.
- [ ] 오류·권한 부족·취소 결과를 사용자에게 표시하고 작성 중 입력을 보존한다.
- [ ] 성공 재시도·중복 이벤트·다른 조직 접근 사례를 테스트한다.

## 단계·검증 기록

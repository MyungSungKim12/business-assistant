# 다지점 운영

갱신일: 2026-09-18 · 상태: planned

## 목적·진입점

지점별 데이터 경계와 본사 조회를 구분하고 직원·재고·회원권 공유 정책을 명시한다. 업무 화면에서 진입하고 관리자용 설정은 공통 설정에 둔다.

## 기능 추적

| ID | 우선 | 상태 | 범위 |
| --- | --- | --- | --- |
| BRANCH-001 | P0 | planned | 지점별 영업/자원/권한 관리 |
| BRANCH-002 | P0 | planned | 본사 비교 지표와 지점별 원천 조회 |
| BRANCH-003 | P1 | planned | 지점 간 재고 이동 출발/도착 확인 |
| BRANCH-004 | P1 | planned | 고객·회원권 공유 여부와 사용 지점 기록 |

## 데이터 계약

branch_id, organization_id, membership_scope, transfer_id, source_branch, destination_branch, sharing_policy. 식별자에는 조직 경계를 적용한다. 기존 API에 없는 필드는 구현 전에 계약과 마이그레이션을 검토한다.

## 업무·복구 흐름

본사 정책과 지점 권한 설정 → 이동 요청 → 출고 → 운송 중 → 입고 확인. 도착 전까지 목적지 가용 재고로 계산하지 않는다.

## 인수 조건

- [ ] 지점 합계와 전체 합계가 일치하고 지점 이동이 이중 매출을 만들지 않는다. 공유 비허용 고객 정보는 다른 지점에 노출되지 않는다.
- [ ] 오류·권한 부족·취소 결과를 사용자에게 표시하고 작성 중 입력을 보존한다.
- [ ] 성공 재시도·중복 이벤트·다른 조직 접근 사례를 테스트한다.

## 단계·검증 기록

소비 메뉴의 P0 흐름에 필요한 최소 기능부터 제공하고, 확장 기능은 별도 검증한다. 2026-09-18 문서 작성; 실환경 검증 없음. 기존 범용 API 존재는 이 문서의 전체 기능 완료 증거가 아니다. 상태 변경 시 [변경 이력](../changelog.md)에 증거와 제한을 기록한다.

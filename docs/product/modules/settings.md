갱신일: 2026-11-02 · 상태: in-progress

## 목적·진입점

## 데이터 계약

organization_id, timezone, policy_version, membership_id, role, permission_codes, subscription_state. 식별자에는 조직 경계를 적용한다. 기존 API에 없는 필드는 구현 전에 계약과 마이그레이션을 검토한다.

## 업무·복구 흐름

관리자가 변경 영향 확인 → 설정 저장 → 시행 시점부터 적용. 소유자 이전과 계정 제거는 미완료 업무·권한 유지 조건을 검증한다.

## 인수 조건

- [ ] UI에서 숨긴 기능도 직접 API 호출 시 같은 권한으로 거부된다. 정책 변경이 이미 확정된 거래 규칙을 소급 변경하지 않는다.
- [ ] 오류·권한 부족·취소 결과를 사용자에게 표시하고 작성 중 입력을 보존한다.
- [ ] 성공 재시도·중복 이벤트·다른 조직 접근 사례를 테스트한다.

## 단계·검증 기록

소비 메뉴의 P0 흐름에 필요한 최소 기능부터 제공하고, 확장 기능은 별도 검증한다. 2026-09-18 문서 작성; 실환경 검증 없음. 기존 범용 API 존재는 이 문서의 전체 기능 완료 증거가 아니다. 상태 변경 시 [변경 이력](../changelog.md)에 증거와 제한을 기록한다.

# 가져오기·내보내기

갱신일: 2026-09-18 · 상태: planned

## 목적·진입점

기존 프로그램에서 전환하는 매장의 고객·상품·잔액 데이터를 검증 후 이관한다. 업무 화면에서 진입하고 관리자용 설정은 공통 설정에 둔다.

## 기능 추적

| ID | 우선 | 상태 | 범위 |
| --- | --- | --- | --- |
| DATA-001 | P0 | planned | CSV/Excel 항목 매핑과 샘플 미리보기 |
| DATA-002 | P0 | planned | 필수값·날짜·전화·중복 후보 검증 보고서 |
| DATA-003 | P1 | planned | 반영 전 건수·금액 합계 확인과 승인 |
| DATA-004 | P1 | planned | 배치별 결과·실패 행 다운로드와 중복 반영 방지 |

## 데이터 계약

import_job_id, source_file_hash, mapping_version, row_number, validation_errors, batch_status, created_record_ids. 식별자에는 조직 경계를 적용한다. 기존 API에 없는 필드는 구현 전에 계약과 마이그레이션을 검토한다.

## 업무·복구 흐름

파일 업로드 → 매핑 → 전체 검증 → 오류 수정 → 반영 확인 → 결과 보고서. 중복 후보는 자동 병합하지 않는다. 실패 재시도는 이미 성공한 행을 제외한다.

## 인수 조건

- [ ] 같은 파일 재실행으로 고객·잔액이 중복 생성되지 않는다. 내보낸 금액·건수와 선택 범위가 일치하고 권한 없는 필드는 제외된다.
- [ ] 오류·권한 부족·취소 결과를 사용자에게 표시하고 작성 중 입력을 보존한다.
- [ ] 성공 재시도·중복 이벤트·다른 조직 접근 사례를 테스트한다.

## 단계·검증 기록

소비 메뉴의 P0 흐름에 필요한 최소 기능부터 제공하고, 확장 기능은 별도 검증한다. 2026-09-18 문서 작성; 실환경 검증 없음. 기존 범용 API 존재는 이 문서의 전체 기능 완료 증거가 아니다. 상태 변경 시 [변경 이력](../changelog.md)에 증거와 제한을 기록한다.

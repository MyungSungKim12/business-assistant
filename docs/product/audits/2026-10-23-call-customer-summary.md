# INT-007 고객 응대 요약 / UX-05 설정 배치 보완

2026-10-23 상태: in-progress. 사용자가 독립 전화 알림창의 실제 전화 표시 성공을 확인하고, 고객 메모·사진·정보를 추가해 달라고 요청했다. 이어 환경 설정의 체크박스/업데이트 UI 깨짐을 화면으로 제보했다. 기본 독립 창의 사용자 확인과 이번 확장 범위의 검증을 구분한다.

## 구현 범위

- 이름·번호와 고객 바로가기부터 즉시 표시한다. 메모/주의사항/태그, 실제 방문일/다음 예약, 최근 완료 시술, 사진을 독립적으로 병렬 조회해 이어 표시한다. 실패한 항목은 조회 실패로 명시하고 재시도하며, 다른 정보와 기본 전화 알림을 유지한다.
- PC 전용 `POST /organizations/:organizationId/phone/caller-profile`: CRM 조직 권한과 번호 정확 일치·고객 ID·활성 상태를 검사하고 메모/알레르기/태그만 반환한다. 모바일 번호부·수신 이벤트에는 상세 정보를 추가하지 않는다. 이 경로는 임시 모바일 게이트웨이 허용 목록 밖이다.
- 방문일과 다음 예약은 기존 실제 방문 사실 API를 재사용한다. 예약의 날짜·시술·담당자를 기존 예약 API로 보완하되 권한/조회 실패 시 이미 확인한 예약 일시는 남기고 실패를 표시한다. 최근 시술은 같은 고객/조직의 완료 기록만 사용한다. 프로필의 수기 방문일을 실제 방문으로 표시하지 않는다.
- 사진은 같은 고객·조직의 최근 JPEG/PNG/WebP 중 10MB 이하를 선택한다. 기존 보호된 서명/다운로드를 거쳐 PC에서 420×280 이하 JPEG로 변환하며, 200KB 이하 data URI만 로컬 IPC로 보낸다. 원본·서명 URL·토큰은 팝업으로 전달하지 않는다. 작은 미리보기와 팝업 내부 확대를 제공한다. 사진이 없거나 형식/용량 제한으로 미리보기를 만들 수 없으면 구분해 표시한다.
- 고객 메모는 기본 3줄 요약과 전체 펼치기를 제공한다. 주의사항·태그·최근 시술·예약을 함께 표시한다. 이미 펼친 메모/사진은 다른 정보가 도착해도 접히지 않는다. 조회 반복으로 등장 애니메이션을 재시작하지 않는다.
- ‘고객 상세 보기’는 기존 메뉴 이동/입력 보호를 거쳐 고객을 선택한다. 중복 번호는 최대 10명의 고객별 상세 버튼을 제공하고 요약을 임의 고객으로 채우지 않는다. 고객이 현재 페이지에 없어도 `GET /customers/:customerId`로 같은 조직/ID의 실제 고객을 읽어 선택한다. 이 경로도 CRM 권한을 검사한다.
- 계정/조직 전환·잠금·로그아웃·만료 후 늦게 도착한 응답을 버린다. 네이티브 창은 길이/사진 형식·용량과 고객 선택 범위를 검증한다. 상세 창의 자격 증명/파일/HTTP 접근 금지는 유지한다.
- 설정 UI: 중첩 div/label을 모두 가로 flex로 취급하던 규칙을 항목별 2열 grid로 수정했다. 자동 업데이트와 버전 확인은 별도 행이다. Windows 알림 테스트 버튼은 별도 우측 정렬 행이다. 체크박스 16×16px 고정, 버튼 줄바꿈 방지, 설정 창 기본 폭을 md로 확대했다.

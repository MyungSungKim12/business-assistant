# HOME-03 사용자별 홈 위젯 구성

기록일: 2026-10-20

## 결정·동작

- 각 사용자는 홈의 예약, 할 일, 다음 방문, 최근 방문, 수입·지출, 재고 부족, 회원권 만료 패널을 개별적으로 표시/숨김하고 순서를 바꿀 수 있다.
- 최소 하나의 패널을 표시한다. 설정은 계정 ID가 포함된 기존 localStorage 사용자 설정에 저장한다. 서버/다른 PC로 동기화하지 않는다.
- 반응형 격자는 넓은 화면 12열, 중간 화면 6열, 좁은 화면 1열이다. 패널별 크기 등급을 유지하면서 DOM 순서로 배치해 숨김/순서 변경 때 지정 격자 칸이 비는 문제를 줄인다.
- 기본 구성은 기존 순서를 유지한다. 설정은 홈의 `홈 구성`에서 체크박스와 위/아래 버튼으로 바꾼다.

## 검증

- `pnpm --filter @business-assistant/desktop-react test -- src/features/dashboard/DashboardPage.test.tsx src/store/preferences.test.ts`: 25개 통과.
- `pnpm --filter @business-assistant/desktop-react build`: 통과. Vite의 기존 500KB 초과 청크 안내가 남았다.
- 실제 Tauri 창·다중 화면 크기에서의 시각적 인수는 하지 않았다. 테스트는 설정 저장/패널 숨김/순서 변경을 소스 수준에서 검증했다.

## 남은 제한

- 설정은 기기 로컬이다. 계정 동기화, 끌어서 놓기, 사용자 정의 패널 크기는 구현하지 않았다.
- APT-15 등 외부 화면으로의 클릭 동작은 기존 패널 동작을 유지한다.

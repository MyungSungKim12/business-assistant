# 현재 남은 작업 — 2026-11-03

## 현재 기준

- 후속 작업 N1030-01~12는 각각의 코드/SQL/문서 범위에서 한정 검증을 마쳤다. 이것은 전체 제품의 실사용 인수나 운영 배포 완료를 뜻하지 않는다.
- Supabase 원격 migration 이력에서 066~112를 확인했다. 107/108 migration은 이력에 `business_member_permissions`, `business_permission_role_ceiling` 이름으로 등록되어 있다.
- 1~12 작업에 대한 증거와 제한은 [완료 추적표](product-completion-2026-10-30.md), 메뉴별 전체 백로그는 [기능 백로그](backlog.md)에 있다. 실사용 확인은 사용자가 요청한 시점에 진행한다.
- 마지막 코드 확인: API 집중 테스트 466건 및 변경 화면 집중 테스트 851건 통과, API와 React production build 성공. 전체 프로젝트 테스트는 실행하지 않았다.
- 해당 작업 소스는 DB/API/화면/Native 앱/Android/검증 스크립트/운영 스크립트/문서 단위의 한글 커밋 8개로 분리되어 `main`에 푸시됐다. 커밋 상세는 [변경 이력](changelog.md)에 기록한다.

### 메뉴별 P1/P2 코드 후속

- **고객관리:** CRM-14 최종 파기 잠금 해제는 보존정책 확정과 종속 데이터/백업 복구 설계 이후 진행한다. CRM-15 사진 영구 파기와 보관 기간은 결정 대기다.
- **예약:** APT-12/15 가용 시간 추천은 실제 매장 근무·자원 조건 검증을 남긴다. APT-13의 대기/반복 예약 전체 흐름과 APT-17 알림·APT-18 온라인 예약은 기능 확장 항목이다.
- **문서/파일:** DOC-11 이메일·문자 전송은 D-01 메시지 업체에 의존한다. FILE-11 외부 링크와 요금제별 용량은 D-21 보안/요금 정책이 필요하다.
- **직원/정산:** TEAM-11 급여·세금 연동, TEAM-12 이메일 초대, FIN-11 카드 대사·영수증 첨부, SALE-12 PG/현금영수증/전자세금계산서, ADM-11 셀프 요금제/청구 이력이 남아 있다.

## 우선순위 2 — 제품 확장 후속

- 홈/경영 수치의 실계정 대사와 지점별 비교·통합 범위 확정.
- 사업자 카드 명세/PG 정산 대사와 거래별 영수증 파일 연결.
- 반복 예약·대기 제안·다지점 이관을 실제 매장 데이터로 검증하고 운영상 예외를 보완.
- 물리 기기 등록부와 분실 기기 원격 삭제가 필요하면 Android 키/세션/조직 등록 구조를 별도 설계한다. 현재 세션 철회는 하드웨어별 원격 삭제가 아니다.

## 범위 및 미실행 항목

이번 잔여 목록은 계획/기록의 최신화다. 실제 PC·휴대폰 업무 인수, 배포, 외부 발송, DB/Storage 복원은 실행하지 않았다. 전체 프로젝트 테스트도 실행하지 않았다. DB 변경이나 신규 업무 기능 코드는 추가하지 않았다.

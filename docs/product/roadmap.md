## 이번 작업의 범위

CRM-001~007은 2026-09-18 로컬 기능 검증 범위에서 verified다. 데스크톱 91개·서버/common 108개 테스트와 화면 검증을 통과했다. 실제 배포 서버 왕복 검증과 응답 불명확 시 멱등성·대량 데이터 성능은 미검증이며 1단계 실운영 승인은 아직 별도다. 상세 증거는 [고객관리 계획](menus/02-customers.md)의 검증 기록을 따른다.

이번 CRM 범위에 포함하지 않는 항목: 고객 병합, 불변 감사 로그, 예약·잔액 실시간 통합, 실제 사진 업로드/가공, 약속·리마인더 자동화. 관련 요구사항은 CRM-008~011과 지원 모듈에 유지한다.

## 다음 작업을 선택하는 방법

1. 메뉴 문서의 P0 중 선행 의존성이 충족된 기능 ID를 선택한다.
2. API 계약·권한·상태 전이·실패 시 복구를 구현 계획으로 구체화한다.
3. 해당 기능의 인수 조건과 공통 게이트에 필요한 증거를 수집한다.
4. 문서 상태와 변경 이력을 갱신하고 미완료 제한을 남긴다.

계획 변경 시 새 기능을 추가하기보다 기존 ID의 범위를 먼저 검토한다. 완료된 기능의 의미를 바꾸면 기존 검증도 재평가한다.

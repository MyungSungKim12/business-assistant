# 개선·추가 작업 목록 (Backlog)

기준일: 2026-10-13. React/Tauri + Node API 전환 이후 남은 보완 사항과 추가 기능을 한곳에서 관리한다. 각 항목은 고정 ID와 상태(`planned / in-progress / done`)를 가진다. 진행하면 상태와 검증 근거를 이 문서와 [변경 이력](changelog.md)에 함께 남긴다.

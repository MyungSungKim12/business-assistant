# 제품 개요

## 누구를 위한 프로그램인가요?

Business Assistant는 고객, 일정, 문서, 매출처럼 반복되는 일을 한곳에서 처리하고 싶은 소규모 사업자와 팀을 위한 Windows 데스크톱 업무 프로그램입니다. 처음에는 한 사람이 쓰는 작은 사업장도 쉽게 시작할 수 있게 만들고, 이후 직원과 조직 단위의 협업으로 넓힙니다.

현재 제품의 중심은 뷰티 매장의 고객·예약·시술 운영을 재고·직원·매출·정산 같은 ERP 업무와 연결하는 것입니다. 공통 업무 구조를 바탕으로 매장별 권한과 업무 흐름을 제공합니다.

## 공통 업무 모듈

현재 메뉴는 홈, 할 일, 고객관리, 예약관리, 시술관리, 매출, 더보기(서비스·직원·회원권·재고·재무·문서·파일·관리·구성원·관리자), 설정으로 구성됩니다. 로그인 사용자와 조직 권한에 따라 일부 메뉴가 달라집니다.

메뉴가 보인다고 모든 기능을 쓸 수 있는 것은 아닙니다. 서버가 구독 상품과 사용자 권한을 확인한 뒤 허용된 기능만 제공합니다.

## 이번 초기 범위

현재 앱은 React 19·Tauri 2 데스크톱 클라이언트와 Node.js·Fastify API를 사용하며, Python 업무 서버와 PySide6 앱은 제거됐습니다. 고객, 예약, 시술, 판매·수납, 재고·회원권, 문서·파일, 직원·관리 기능이 구현되어 있습니다. 화면과 API의 코드 구현, SQL 적용 보고, 실 Supabase 흐름의 독립 검증은 구분해서 봐야 합니다. 출시 전 인수 잔여는 [개선·추가 작업 목록](product/backlog.md)과 [기능 대응표](product/react-tauri-parity.md)에 기록합니다.

## 이번 단계에서 하지 않는 일

- 운영 서버 배포와 Windows 설치·업데이트의 실제 인수
- 모든 SQL/RPC 흐름의 스테이징·운영 적합성 확인
- 결제대행사 연결과 외부 초대 메일 발송
- 일부 P2 운영 보완(소모품 자동 차감, 감사 로그 화면·보관 정책)

## 다섯 단계 로드맵

1. **앱 기반 전환**: React/Tauri와 Node/Fastify 기반 구현을 완료했습니다.
2. **사용자와 조직**: 인증·조직·역할·구독 권한 흐름을 구현했습니다.
3. **매장 운영 기능**: 고객·예약·시술·판매·재고·회원권·문서 기능을 구현했습니다.
4. **운영 인수**: SQL과 권한 흐름을 테스트 조직에서 확인하고 제한사항을 기록합니다.
5. **상용화**: API 배포, Windows 설치·업데이트, 백업과 모니터링을 검증합니다.

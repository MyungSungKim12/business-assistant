# 제품 개요

## 누구를 위한 프로그램인가요?

Business Assistant는 고객, 일정, 문서, 매출처럼 반복되는 일을 한곳에서 처리하고 싶은 소규모 사업자와 팀을 위한 Windows 데스크톱 업무 프로그램입니다. 처음에는 한 사람이 쓰는 작은 사업장도 쉽게 시작할 수 있게 만들고, 이후 직원과 조직 단위의 협업으로 넓힙니다.

업종마다 용어와 절차는 다르지만 고객 관리, 일정, 문서, 파일, 보고서라는 공통 업무는 비슷합니다. 이 프로그램은 공통 기능을 먼저 제공하고, 학원·미용실·부동산 같은 업종별 기능은 나중에 독립 모듈로 추가합니다.

## 공통 업무 모듈

초기 메뉴는 홈 대시보드, 고객·거래처, 일정·할 일, 문서 자동화, 매출·지출, 파일·자료, 데이터 가져오기·내보내기, 보고서·분석, 업무 자동화, AI 업무 도우미, 알림센터, 팀·직원, 외부 서비스 연동, 계정·구독, 환경설정으로 구성합니다.

메뉴가 보인다고 모든 기능을 쓸 수 있는 것은 아닙니다. 서버가 구독 상품과 사용자 권한을 확인한 뒤 허용된 기능만 제공합니다.

## 이번 초기 범위

이번 단계에서는 Python 3.13 기반 개발 환경, FastAPI 서버의 상태 확인 API, PySide6 데스크톱 최소 창, 공통 타입, 테스트와 품질 검사, 개발 문서를 제공합니다. Supabase 자격 증명이 없어도 기본 골격과 테스트는 실행할 수 있습니다.

## 이번 단계에서 하지 않는 일

- 실제 Supabase 프로젝트 생성과 운영 자격 증명 연결
- 완성된 회원가입·로그인 화면
- 실제 결제대행사 연결
- 고객 관리 등 업무 화면의 상세 기능
- 배포 서버, 자동 업데이트, Windows 설치 파일

## 다섯 단계 로드맵

1. **프로젝트 기반**: 개발 도구, 서버·데스크톱 골격, 테스트와 문서를 준비합니다.
2. **사용자와 조직**: 로그인, 세션, 프로필, 조직과 직원 역할을 구현합니다.
3. **구독과 권한**: 상품, 기능 코드, 구독 상태, 등록 기기 제한을 연결합니다.
4. **범용 업무 기능**: 고객, 일정, 문서, 매출, 보고서 같은 공통 업무를 만듭니다.
5. **상용화**: 결제, 설치 파일, 업데이트, 배포, 백업과 모니터링을 준비합니다.

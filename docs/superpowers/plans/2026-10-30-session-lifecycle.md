# R1030-01 / SEC-14 세션 수명주기 보완

사용자가 높은 우선순위부터 순차 구현을 요청해 첫 번째 세션 경쟁 문제를 수정한다. 대상은 PC ApiClient이며 UI/DB/원격 세션 정책은 변경하지 않는다.

- [x] 늦은 refresh 성공/실패, 새 계정 로그인, 로그아웃 중 토큰 저장, 늦은 일반/void 응답을 실패 테스트로 재현한다.
- [x] 세션 generation으로 login/signup/logout 전환 이전 응답과 인증 재시도를 차단한다. 토큰 저장/삭제를 직렬화하고 오래된 실패가 새 계정을 지우지 못하게 한다.
- [x] 기존 동시 401 단일 갱신과 네트워크 장애 시 refresh-token 보존 동작을 유지한다.
- [x] 인증/로그인 화면 집중 61 tests·타입 검사·빌드 통과 후 증거 기록. 전체 테스트·실데이터 변경·커밋/푸시 없음.

상태: 로컬 코드 범위 verified. 이미 서버에 전달된 업무 요청을 취소하거나 서버 세션을 폐기하는 작업은 이 수정 범위가 아니다. 다음 작업은 R1030-02 대량 목록 조회 일관성이다.

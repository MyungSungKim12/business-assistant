# React/Node 문서 최신화 및 레거시 자료 정리 계획

**목표:** 현재 React/Tauri + Node API 구조와 실제 진행 상태를 중심 문서와 사용자 가이드에 반영하고, 과거 작업 기록은 보존하면서 오래된 안내와 불필요한 루트 파일을 정리한다.

**범위:** 실행 구조·메뉴·백로그·검증 한계 문서, 과거 Python 모듈 보고서 보관 위치, 레거시 참조 조사.

## 작업 순서

1. 저장소 지침, 최신 handoff/backlog, 실행 스크립트와 문서 링크를 대조한다.
2. 현재 제품 인덱스·로드맵·상태표·아키텍처·빠른 시작 안내를 React/Tauri + Node API 기준으로 갱신한다.
3. 과거 설계/계획/테스트 기록은 삭제하지 않는다. 루트의 Python-era 모듈 보고서 5개는 참조를 확인한 뒤 archive로 이동하고 보존 안내를 추가한다.
4. 코드에서 참조되지 않는 과거 앱 소스가 없는지 다시 확인한다. 현재 소스 삭제는 근거가 명확한 경우에만 수행한다.
5. 가이드 빌드/검증과 링크·상태·diff 점검으로 결과를 확인하고 변경·제한을 changelog에 남긴다.

## 검증 기준

- 현재 실행 구조와 상태가 README, 제품 인덱스, 개발자/사용자 안내에서 서로 일치한다.
- 루트의 과거 보고서 기록은 내용 손실 없이 보존되고 archive 색인에서 찾을 수 있다.
- 기록용 계획·설계·릴리스 문서는 삭제되지 않는다.
- MkDocs strict 검증과 `git diff --check`가 통과한다.

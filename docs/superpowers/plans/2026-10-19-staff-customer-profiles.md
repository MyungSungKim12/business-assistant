# F14 직원·고객 프로필 보완

기능 TEAM-001 / CRM-001, 감사 F14. 상태 in-progress. 사용자는 SQL 062 적용 완료를 보고했다.

1. 고객 기존 필드 birth_date/skin_type/concerns/allergies를 폼에 연결한다. 실패·고객 전환 입력 보호·읽기 전용을 유지하고 날짜 API 형식을 ISO date로 제한한다. 기존 last/next 수기 날짜도 ISO date 검증만 적용한다.
2. SQL 063에 예약 담당 이름/활성 변경 RPC와 profile_version을 추가한다. 관리자 전용·조직·멱등·낙관적 버전 검증. 미래 예약/진행 중 방문이 있으면 중지를 거절하고 먼저 재배정/처리하도록 한다. 직원 삭제·과거 기록 변경·구성원 역할 변경은 하지 않는다.
3. 저장과 담당 중지 경합을 공유 advisory lock으로 직렬화한다. 기존 예약 저장이 활성 상태를 lock 전에 확인하므로 INSERT/배정·시간·상태 UPDATE의 트리거에서 lock 후 재확인한다. 구버전 저장 RPC도 보호한다.
4. API·클라이언트 스키마/수정 팝업 연결. 작성/실패 보존, 중지 확인, 409 안내·재시도, 권한 유지. 새 SQL 미적용시 저장 기능을 비활성화한다.
5. 집중 DB/API/React 테스트와 타입 검사·독립 리뷰·제품 기록. 전체 테스트·앱 실행·운영 DB·커밋/푸시 없음.

직원 계정/구성원 연결과 자동 재배정은 후속이며 중지된 담당의 과거 예약/시술 이력은 그대로 보존한다.

구현·집중 검증: API 63개·React 81개·격리 DB·양쪽 타입 검사 통과. 독립 리뷰의 상태만 바꾸는 과거 예약 방문 누락을 재현·수정·재확인했다. SQL 063 원격 미적용·다중 세션 경합/실앱 미검증. [제품 기록](../../product/audits/2026-10-19-staff-customer-profiles.md).

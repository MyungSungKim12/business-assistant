# 시술 전 확인 연결 — 2026-10-20

대상: TRT-001 / TRT-003 (기존 in-progress 유지). 선행: CRM 고객 주의정보, 상담 스냅샷, DOC 불변 발행본·동의 이벤트·증빙 검증 API.

1. 기존 디자인 안에 읽기 전용 ‘시술 전 확인’ 창을 연결한다. 작성 중인 시술 입력은 저장 후 진입한다.
2. 창을 열 때 최신 고객·시술과 해당 시술 발행본을 읽는다. 상담 목표·확인자/시각·주의정보 변경을 구분한다. 고객 조회 실패와 문서 조회 실패를 각각 표시하고 재시도한다.
3. 문서를 선택할 때만 이벤트와 서명 증빙을 조회한다. 발행/손서명/교부/철회/증빙 불일치/증빙 없음/조회 실패를 구분하며 ‘동의 완료’로 묶지 않는다. 상담·문서 작업 창으로 연결한다.
4. 이전 조직·고객·시술·문서의 늦은 응답을 무시한다. 서버의 기존 시작 조건과 권한 검사는 유지한다. 새로운 필수 동의 정책이나 동의서 자동 선택·저장을 도입하지 않는다.
5. 관련 React/API 테스트와 타입 검사만 수행한다. 실제 앱·운영 DB·전체 테스트·커밋은 하지 않는다. 문서에 검증된 범위와 남은 정책을 기록한다.

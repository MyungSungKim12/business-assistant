# INT-007 Windows 전화 알림창 구현 계획

사용자 승인: 2026-10-23 ‘별도 알림창 + 애니메이션’ 선택. 기존 업무 화면 대신 최소화·트레이 상태에서도 볼 수 있는 오른쪽 아래의 독립 창을 사용한다.

기술 선택: Windows 기본 배너는 OS가 애니메이션을 제어하므로, 기존 Tauri의 독립 WebviewWindow를 사용한다. 별도 외부 라이브러리 없이 CSS 등장/강조 애니메이션을 적용하고 동작 줄이기 설정을 존중한다. 고객명·번호는 로컬 IPC로만 전달하며 URL/로그/디스크에 쓰지 않는다.

- [x] 네이티브 창: 포커스 강탈 없이 항상 위에 표시, 작업 표시줄 제외, 작업 영역 오른쪽 아래 배치, 최근 전화 최대 3건·2분 만료, 닫기 및 메모 버튼 구현.
- [x] React 연결: 브라우저는 기존 앱 내 카드 유지, 네이티브 실패 시 카드로 복구, 메모 작성 시 메인 창 복원, 계정/매장 이동·로그아웃·앱 잠금 시 초기화 구현.
- [x] 검증: React 집중 38 tests·타입 검사, Rust 집중 2 tests/빌드 및 독립 HTML 번들 확인. 실제 전화/최소화 화면 인수와 구분해 기록. 커밋/푸시 없음.
- [ ] 실제 최소화·트레이·다중 모니터 및 장시간 숨김 상태 전화 인수.

진행: in-progress. Windows 기본 배너 설정/테스트 버튼은 전화 알림창과 별도로 예약·할 일 알림에 재사용한다.

# DOC-001 템플릿 버전 관리 실행 계획

기존 문서 메뉴에 초안 저장 → 게시 → 새 버전 초안 → 게시/폐기를 연결한다.
사용자가 승인한 순차 구현 범위다. 담당: Codex. 실제 DB 적용·배포·커밋 없음.

- 기존 템플릿은 초안, 기존 보관 템플릿은 폐기로 이관한다. 과거 게시 사실을 만들지 않는다.
- 현재 템플릿에 status, version(서식 버전), revision(낙관적 잠금)을 둔다.
- 게시 시 별도 불변 스냅샷과 게시자/서버 시각을 저장한다. 수정은 새 버전 초안으로만 가능하다.
- 같은 작업 ID 재시도는 중복 생성하지 않는다. 변경된 요청으로 ID 재사용 시 충돌한다.
- API 기능 권한·조직 역할 검사와 DB 조직/관리자 검사를 함께 적용한다.
- 관리 대화상자는 비동기 통신, 실패 입력 유지, 충돌 안내, 이동·종료 시 버리기 확인을 제공한다.
- DOC-002 고객값 자동 채움, DOC-003 발행본 연결, DOC-004 서명은 후속 범위다.

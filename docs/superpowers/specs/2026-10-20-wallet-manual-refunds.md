# WAL-11 관리 입력형 회원권 환불 설계

## 목표
할인 판매·횟수권·복합권도 관리자가 매장 환불 정책에 따라 실제 외부 환불액과 제거할 잔여 혜택을 각각 명시해 기록한다. 시스템은 혜택의 금전 가치를 추정하지 않는다.

## 동작
- 관리자 미리보기는 원 결제액, 누적 현금 환불액, 남은 환불 한도, 현재 금액·횟수 잔액, 잔액 버전을 보여준다.
- 환불 기록 요청은 실제 외부 환불액(양수), 제거할 금액 잔액(0 이상), 회수할 횟수(0 이상), 사유, 현재 잔액 버전, 멱등 키, 외부 환불 완료 확인을 요구한다. 세 금액/수량 중 실제 환불액은 양수이고 제거 혜택 중 적어도 하나는 양수여야 한다.
- 외부 환불액 누계는 원 판매 결제액을 넘지 못한다. 혜택 제거량은 현재 잔액을 넘지 못한다. 각 값은 서로 환산하지 않는다.
- 혜택 제거와 현금 재무 지출, 불변 환불 이벤트 기록은 원자적으로 처리한다. 전체 혜택이 0이면 회원권 상태를 refunded로 닫는다.
- 수당 환불 조정은 실제 외부 환불액만 사용한다. 내역에는 현금·금액·횟수 변동을 각각 표시한다.

## 보안/한계
조직 관리자만 가능하며 동일 조직/고객/판매 회원권, 활성·유효한 회원권, 버전 일치, 마감되지 않은 수당 기간, 권한과 멱등성을 확인한다. 결제사를 호출하지 않는다. 이 기능은 실제 환불이 외부에서 완료됐다는 확인을 기록하며, 환불액 또는 잔여 혜택의 적정성은 점주가 확정해야 한다. 기존 8인자 RPC는 단순 금액권 호환용으로 유지하되 새 관리 화면은 분리 입력 RPC를 사용한다.

# TEAM-11 수당 담당 누락 보정 설계

## 목표

수당 미리보기에서 담당 직원이 누락된 판매 항목을 점주/관리자가 사유와 함께 직원에게 귀속하고, 기존 시행 수당 규칙으로 다시 계산할 수 있게 한다.

## 제약

- 보정은 sale line의 원본 담당자 정보를 덮어쓰지 않고 별도 귀속 오버라이드와 불변 이력으로 저장한다.
- 관리자는 조직 내 활성 직원만 선택할 수 있고, 보정 사유는 필수다.
- 금액·수당률은 입력받지 않는다. 이벤트 발생일 기준의 기존 수당 규칙과 미리보기의 순수납 배분으로 금액을 계산한다.
- 기간이 이미 확정되었거나 다른 조직/판매 항목/직원인 경우 보정을 거부한다.
- expected version과 operation id로 동시 수정과 재시도 중복을 방지한다.
- 분할 담당자 배분, 급여·세금 원천징수, 급여 이체는 이 작업 범위가 아니다.

## 구성

SQL 093은 현재 귀속 상태와 append-only 수정 이벤트를 만든다. 관리자 전용 RPC는 조직·직원·판매 항목을 검증하고, 기존 수당 미리보기 함수의 결과를 오버라이드 직원으로 재평가한다. API는 엄격한 입력 검증과 관리자 권한을 적용한다. 경영 수지의 수당 미리보기 화면에서는 담당 누락 행에 직원과 사유를 입력하고 보정 후 다시 조회한다.

## 검증 기준

- 미지정 항목은 기존처럼 경고되어 정산을 막는다.
- 보정 후에는 직원 이름·기존 시행 수당 규칙·계산액이 표시되고, 기간 정산이 가능하다.
- 환불은 환불 발생일의 유효 규칙을 사용한다.
- 빈 사유, 비활성/다른 조직 직원, 이미 확정된 기간, 오래된 version, operation id 충돌은 거부된다.
- 동일 operation id 재시도는 동일 결과를 반환하고 수정 이력을 중복 추가하지 않는다.
- 다른 조직 사용자와 일반 구성원은 보정 API/RPC를 실행할 수 없다.

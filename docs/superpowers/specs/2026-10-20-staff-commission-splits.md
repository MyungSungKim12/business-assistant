# TEAM-11 복수 담당자 수당 배분 설계

## 목적

하나의 판매 항목을 실제로 함께 수행한 여러 직원에게 배분하고, 각 직원의 기존 시행일별 수당 규칙으로 정산한다.

## 결정 및 범위

- owner/admin이 장바구니 검토 단계에서 판매 항목마다 담당 직원과 배분율을 지정한다. 기본은 기존 주 담당자 100%이며, 추가 직원이 있으면 비율을 수동 입력한다.
- 입력 비율은 basis point 정수로 저장하고 합계는 정확히 10,000이어야 한다. 퍼센트 합계가 맞지 않으면 저장하지 않는다.
- 실제 순수납 이벤트의 금액을 항목별로 비례 배분한 뒤 직원 비율을 적용한다. 직원별 소수 원 반올림 후 마지막 직원이 남은 원 단위 차액을 받는다. 환불은 원래 항목과 고정된 직원 비율에 따라 음수 조정한다.
- 각 직원 몫에는 그 직원에게 유효한 수당 규칙을 적용하고, 없으면 기존 조직 기본 규칙을 적용한다. 수당률·금액을 직접 입력하지 않는다.
- 배분은 결제 전 장바구니에서만 변경할 수 있다. 원본 주 담당자 필드는 레거시 조회와 호환을 위해 유지한다. 직원별 정산 내역은 직원 API 범위 제한을 그대로 따른다.
- 최대 배분 인원은 판매 항목당 10명, 각 몫은 최소 1bp다. 동일 직원 중복, 비활성/다른 조직 직원, 합계 불일치는 거부한다.

## 제외

퇴사 이후 정산 조정, 급여 이체/세금, 임의 총액 수당, 결제 완료 후 귀속 변경은 포함하지 않는다. 이미 확정된 정산은 수정하지 않는다.

## 검증

장바구니 판매 라인 변경에서 배분 상태를 원자적으로 저장하고, 중복/범위/비율/버전 오류를 거부한다. 수납·회원권 사용·환불 각각이 동일한 비율로 나뉘며 소수 원 잔액 보정, 직원별 규칙 차이, 직원 본인 열람 제한을 격리 DB/API/React에서 확인한다.

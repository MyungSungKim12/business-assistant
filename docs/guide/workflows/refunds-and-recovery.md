# 환불·취소·미확인 복구

금액, 재고와 회원권을 바꾸는 작업은 기존 기록을 삭제하지 않고 반대 원장을 추가합니다.

## 환불

1. 결제 장바구니에서 고객과 방문을 선택합니다.
2. **수납 기록 · 내역 → 환불 · 사용 취소**를 엽니다.
3. 원수납을 선택합니다.
4. 환불 가능 금액 안에서 금액과 사유를 입력합니다.
5. 실제 환불 확인을 체크하고 **환불 기록**을 누릅니다.

현금·카드·이체는 부분 환불할 수 있습니다. 환불액은 원수납 금액과 이미 환불한 금액을 합한 한도를 넘을 수 없습니다.

## 회원권 사용 취소

회원권 사용 원장을 선택하고 전체 취소합니다. 부분 사용 취소는 지원하지 않습니다. 취소되면 혜택 잔액과 방문 미수금이 함께 다시 계산됩니다.

## 전체 취소의 연쇄 처리

상품이나 회원권 판매를 전체 환불하면 다음 반대 기록이 함께 필요할 수 있습니다.

- 실물 상품 재고 복원
- 아직 사용하지 않은 발급 회원권 취소
- 재무 원장에 환불 지출 기록

이미 사용된 회원권처럼 자동 취소할 수 없는 연결 기록이 있으면 화면의 거절 사유를 확인하고 관리 절차로 처리합니다.

## 결과를 확인하지 못했을 때

네트워크가 끊기거나 서버 응답이 늦으면 작업 성공 여부를 추측하지 않습니다.

| 작업 | 사용할 버튼 |
| --- | --- |
| 상품 입고·장바구니 변경 | **같은 요청 재시도** |
| 수납 | **미확인 수납 다시 확인** |
| 회원권 사용 | **미확인 사용 다시 확인** |
| 환불·사용 취소 | **미확인 환불 다시 확인** |

복구 버튼은 PC에 보관된 원래 요청 식별자로 서버 결과를 다시 확인합니다. 화면을 닫기 전에 미확인 상태가 해소되었는지 확인합니다.

!!! danger "하지 말아야 할 행동"
    미확인 상태에서 새 방문, 새 수납 또는 새 환불을 만들지 마세요. 새 작업은 원래 요청과 다른 식별자를 사용하므로 중복 업무가 생길 수 있습니다.

# 화면 구성과 기본 조작

Business Assistant는 Native Tauri 창에서 실행됩니다. 개발 중 브라우저 미리보기로 연 경우에도 기본 메뉴와 업무 흐름은 같습니다.

## 상단 메뉴

상단에는 홈, 할 일, 고객관리, 예약관리, 시술관리, 매출 등 자주 쓰는 업무 메뉴가 있습니다. 부가 메뉴는 **더보기** 패널에서 서비스, 직원, 회원권, 재고, 재무, 문서, 파일, 관리, 구성원 등으로 이동합니다. 설정과 알림, 전체 검색은 상단 우측의 공통 도구를 사용합니다. 사용자의 조직 역할이나 구독 권한에 따라 표시 항목이 달라질 수 있습니다.

메뉴가 보이지 않으면 먼저 올바른 조직에 들어와 있는지와 해당 계정에 필요한 역할·기능 권한이 있는지 확인하세요. 화면에서 메뉴를 숨기는 것과 서버에서 요청 권한을 검사하는 것은 별도이며, 서버가 모든 보호된 요청을 다시 확인합니다.

## 업무 화면

목록 화면에서는 검색·필터·정렬로 대상을 찾고, 행이나 카드를 선택해 상세 정보를 봅니다. 새 항목을 만들거나 기존 값을 바꿀 때는 화면의 저장·취소 동작을 사용하세요. 창 크기를 줄이면 일부 목록 영역 안에서 스크롤하며, 작성 중인 내용을 유지할지 묻는 화면에서는 내용을 저장하거나 취소한 뒤 이동합니다.

예약, 시술, 판매·수납, 회원권, 재고와 문서처럼 데이터에 영향을 주는 기능은 메뉴별 사용 안내를 따릅니다. 금액이나 원장을 바꾸는 요청 결과가 불분명하면 같은 작업을 새로 만들지 말고 해당 화면의 재확인·복구 동작을 먼저 사용하세요.

## 공통 도구

- **전체 검색:** 고객이나 업무 대상을 검색하고, 지원하는 결과는 선택한 화면으로 이동합니다.
- **알림:** 앱 안에서 예약·할 일 등 확인이 필요한 항목을 봅니다.
- **설정:** 계정·앱 설정과 개인정보 표시 관련 옵션을 관리합니다.
- **더보기:** 자주 쓰는 상단 메뉴 외의 운영·관리 메뉴를 엽니다.

## 창과 연결 오류

`run-app.cmd`로 앱을 실행하면 API 서버 준비 뒤 Native 창을 엽니다. 서버 연결이 끊기거나 조회에 실패하면 화면의 재시도 동작을 사용하고, 반복되면 API 상태 주소 `http://127.0.0.1:8000/api/v1/health`와 실행 터미널 로그를 확인합니다. 서버 실행 절차는 [빠른 시작](quick-start.md), 설치 앱의 주소 설정은 [운영 안내](../admin/react-tauri.md)를 참고하세요.

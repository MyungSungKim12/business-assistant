# 전체 메뉴 상태

!!! tip "화면별 사용 가이드"
    각 화면의 할 수 있는 일, 단계별 사용법, 권한·주의사항, 자주 막히는 상황은 탭으로 나눈 [화면별 사용 가이드](../assets/screen-guide.html)에서 볼 수 있습니다(기능마다 사용 가능·설정 필요·준비 중 배지가 붙어 있습니다).

Business Assistant는 Windows Native Tauri 앱입니다. 상단에는 주요 메뉴가 있고, 나머지 메뉴는 **전체 메뉴** 패널에서 업무 그룹별로 엽니다. 구독과 사용자 역할에 따라 일부 항목은 표시되지 않습니다.

표의 “화면 연결”은 현재 앱에서 해당 화면을 열 수 있다는 뜻입니다. 실 Supabase 쓰기·복구·정산까지 운영 인수됐다는 의미는 아닙니다. 실제 인수 범위는 [제품 backlog](../../product/backlog.md)와 [React/Tauri 기능 대응표](../../product/react-tauri-parity.md)를 확인하세요.

| 메뉴 | 위치 | 현재 연결 범위 | 남은 인수 예 |
| --- | --- | --- | --- |
| 홈 | 상단 | 운영 요약, 오늘 예약·할 일·미수·재고, 원본 화면 이동 | 테스트 조직 자료 정확성 확인 |
| 할 일 | 상단 | 등록·수정·완료·삭제, 라벨·체크리스트, 반복, 담당자 지정·완료자 기록, 고객·예약 연결, 일괄 완료 | 실제 Windows 알림 확인 |
| 고객관리 | 상단 | 고객 검색·등록·수정·보관, 태그, 중복 병합, 활동·사진, 가져오기/내보내기 | 병합 복구·Storage 업로드 왕복 |
| 예약 | 상단 | 달력, 예약 등록·수정·끌어서 이동, 상태 변경과 노쇼 사유·이력, 대기 목록과 예약 전환, 담당자·서비스·공간·장비 가용성 | 실제 DB 충돌·대체 흐름 인수 |
| 시술 | 상단 | 상담·시술 기록·상태·정정 이력, 동의 문서·시술 사진 연결 | 동의 증빙과 재고·회원권 연동 |
| 매출 | 상단 | 방문 장바구니, 할인, 복합 수납·환불, 상품·회원권 반영, 매출 내역 | 수납·환불·마감 원장 왕복 |
| 서비스 | 전체 메뉴 → 매장 운영 | 서비스 가격·소요 시간·필수 공간/장비 설정 | 직원별 가능 서비스 연결 |
| 직원 | 전체 메뉴 → 매장 운영 | 담당자 프로필·근무·휴무·중지/재활성화, 서비스별 담당 가능 직원, 구성원 역할 관리 | 초대 발송·수당 정산 |
| 회원권 | 전체 메뉴 → 매장 운영 | 잔액·횟수·이력, 정지·재개·기간 연장 | 양도·환불, 시술 자동 차감 |
| 재고 | 전체 메뉴 → 매장 운영 | 상품·안전재고·입고·실사·조정·판매 이력, 공급처·발주·부분 입고 | 로트·유통기한, 시술 소모품 실계정 확인 |
| 정산 | 전체 메뉴 → 정산·문서 | 수입·지출, 반복 지출, 세무용 내보내기, 미수금, 일/월 마감 | 실제 입금 대사·증빙·세무 출력 |
| 문서 | 전체 메뉴 → 정산·문서 | 서식 버전, 문서 발행, 동의·서명 이력, PDF | 실제 발행본 증빙 검토 |
| 파일 | 전체 메뉴 → 정산·문서 | 파일 목록, 폴더·태그, 미리보기, 업로드·다운로드·보관 | Storage 실환경과 보관 정책 |
| 경영 | 전체 메뉴 → 관리 | 담당별 매출 근거와 운영 수지 미리보기 | 원가·수당 포함 확정 손익은 아님 |
| 구성원 | 전체 메뉴 → 관리 | 조직 구성원 추가·역할 변경·제거 | 초대 이메일은 지원하지 않음 |
| 감사 로그 | 전체 메뉴 → 관리 | owner/admin의 작업 이력 검색·상세·페이지 이동 | 무기한 보관 기본값, 실계정 역할별 인수 대기 |
| 구독 | 전체 메뉴 → 관리 | 플랫폼 관리자 전용 조직 플랜 관리 | 별도 관리자 API 배포 필요 |
| 설정 | 상단 오른쪽 | 앱 설정, 개인정보 가림, 자동 잠금·업데이트 상태 | 항목별 상세는 설정 화면 참고 |

## 아직 인수할 주요 흐름

- 전체 순서와 수행 방법은 [기능 테스트 방법 가이드](../../product/functional-test-guide.md)를 따릅니다.
- 테스트 조직에서 예약 충돌, 고객 병합, 구성원 권한 변경, 동의·사진 업로드를 확인합니다.
- 수납 → 매출 내역 → 환불·재고/회원권 역분개 → 일·월 마감 흐름을 대조합니다.
- 새 PC에서 서명된 Native 설치본과 업데이트·복구 절차를 확인합니다.

전체 실행은 `run-app.cmd`를 사용합니다. 브라우저에서 열리는 `scripts/run-react-web.ps1`은 개발 미리보기입니다. 상세 실행법은 [빠른 시작](../getting-started/quick-start.md)을 확인하세요.

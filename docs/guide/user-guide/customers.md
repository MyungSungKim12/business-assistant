# 고객관리

고객관리에서는 고객을 검색하고 기본 정보, 메모, 상담 활동과 사진을 한 화면에서 관리합니다.

![고객관리 화면](../../screenshots/remodel-customers.png)

## 고객 찾기

1. **고객명 또는 연락처 검색**에 이름이나 전화번호 일부를 입력합니다.
2. 고객 카드를 선택합니다.
3. 오른쪽 프로필과 **상담 이력 · 사진 · 메모** 탭을 확인합니다.

고객을 바꾸면 해당 고객의 사진과 활동만 불러옵니다. 사진 로딩이 끝나기 전에도 기본 정보와 상담 이력은 사용할 수 있습니다.

## 신규 고객 등록

1. 상단의 **고객 등록**을 누릅니다.
2. 이름, 연락처, 생년월일, 성별, 태그와 메모를 입력합니다.
3. **고객 등록**을 누릅니다.

같은 전화번호가 이미 있는지 검색한 뒤 등록하면 중복 고객을 줄일 수 있습니다. 관리자 권한이 없는 사용자는 고객 정보를 읽기 전용으로 볼 수 있습니다.

## 고객 정보 수정과 보관

고객 카드를 선택해 정보를 수정한 뒤 **정보 저장**을 누릅니다. 삭제 아이콘은 고객을 즉시 영구 삭제하는 기능이 아니라 제품 정책에 따른 보관 동작으로 취급합니다. 실제 삭제·복원 범위는 [고객관리 제품 계획](../../product/menus/02-customers.md)에서 확인합니다.

## 상담 이력 추가

1. 고객을 선택하고 **상담 이력** 탭을 엽니다.
2. 활동 종류, 제목과 내용을 입력합니다.
3. **활동 추가**를 누릅니다.

프로필 메모에는 장기간 유지할 고객 특성을, 상담 이력에는 날짜별 상담·연락 사실을 기록합니다. 시술 내용은 시술관리에서 관리합니다.

## 사진 등록

1. 고객을 선택합니다.
2. **사진** 탭 또는 **사진 보기**를 누릅니다.
3. **사진 추가**에서 이미지 파일을 선택합니다.
4. 업로드 상태가 **사진 업로드 완료**가 될 때까지 고객을 바꾸거나 앱을 닫지 않습니다.

업로드를 중단하려면 **업로드 취소**를 누릅니다. 네트워크가 끊겨 결과를 확인하지 못했다면 **업로드 다시 시도**를 사용합니다. **사진 새로고침**은 저장된 목록을 다시 조회합니다.

!!! tip "사진 이름"
    한글이나 공백이 포함된 원본 이름도 서버가 안전한 저장 경로로 변환합니다. 과거에 잘못 저장된 경로가 있다면 새 업로드를 반복하기보다 [사진 오류 해결](../troubleshooting.md#400-503)을 따릅니다.

## 시술관리로 이동

선택 고객의 **시술관리 열기**를 누르면 같은 고객이 선택된 시술관리 화면으로 이동합니다. 작성 중인 고객 정보가 있으면 먼저 저장 여부를 확인합니다.

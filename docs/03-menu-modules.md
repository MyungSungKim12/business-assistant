# 현재 메뉴와 권한 모듈

이 문서는 현재 React/Tauri 앱의 메뉴와 API 권한 경계를 설명합니다. 상세 요구사항과 인수 상태의 기준 문서는 [제품 인덱스](product/README.md), [메뉴 상태](guide/user-guide/menu-status.md), [기능 대응표](product/react-tauri-parity.md)입니다.

## 메뉴 구성

상단 주요 메뉴: 홈, 할 일, 고객관리, 예약, 시술, 매출.

전체 메뉴 패널:

- 매장 운영: 서비스, 직원, 회원권, 재고
- 정산·문서: 정산, 문서, 파일
- 관리: 경영, 구성원, 구독

전체 메뉴와 구성원 관리, 구독 관리 항목은 역할 또는 플랫폼 관리자 여부에 따라 표시 여부가 달라집니다. 메뉴가 보이지 않더라도 API 권한은 서버에서 다시 검사합니다.

## 기능 코드와 역할

기능 코드는 메뉴 위치가 아니라 구독 entitlement와 서버 권한으로 평가합니다. 고객은 `crm.basic`, 예약·할 일 등 각 업무는 모듈에 대응하는 기능 코드를 사용합니다. API는 요청마다 사용자 세션, 조직 멤버십, 기능 entitlement, 읽기/변경 역할을 검사하며 PostgreSQL RLS를 추가 경계로 사용합니다.

일반 API는 사용자 JWT로 Supabase REST/RPC를 호출합니다. 서비스 키가 필요한 플랫폼 구독 작업은 `scripts/run-admin.ps1`로 별도 실행하는 관리자 API에서 처리합니다. 서비스 키, DB 비밀번호는 Tauri 앱에 넣지 않습니다.

## 상태·검증 기준

- 메뉴가 연결됨: 화면 진입과 API 계약이 코드에 존재합니다.
- 로컬 검증됨: 자동 테스트와 격리 DB 계약을 통과했습니다.
- 실환경 인수됨: 테스트 조직에서 저장·재조회·거절·재시도·권한 경계를 확인했습니다.
